# 极简结构拼贴视觉规范

## 1. 版式骨架

默认坐标基于 `1024 × 1536 px`：

| 区域 | 坐标 | 作用 |
| --- | --- | --- |
| 实拍区 | `x 0–1024, y 0–768` | 原照片的等比裁切，不做生成式重绘 |
| 构成区 | `x 0–1024, y 768–1536` | 暖纸底上的抽象关系构成 |
| 分界 | `y=768` | 0–4 px 的自然硬切或极细暖纸色接缝 |

允许上下比例在 `48:52` 到 `52:48` 间微调，但只有在主体裁切明显改善时使用。默认坚持 `50:50`，避免版式漂移。

## 2. 上半区：照片保真

上半区的审美来自构图，不来自 AI 美化。

- 允许：读取 EXIF、方向纠正、等比缩放、裁切、无损合成。
- 禁止：生成式重绘、补脸、瘦身、五官修正、磨皮、锐化、HDR、降噪、滤镜、局部换色、非等比缩放。
- 纵向照片进入 4:3 横向面板时，首选 `cover` 裁切；以主体为焦点上下移动裁切窗口。
- 若安全裁切会破坏必要动作或完整物件，第二选择是 `extend`：只让生成模型补外围背景，再把原照片完整区域无羽化回贴。外围不得出现人物、手、餐具或其他主体的复制品。
- 背景无法自然延展时才用 `contain`；空边使用与下半相同的暖纸色。这是“默认横向满幅”规则的例外。
- 不使用镜像或复制边缘补宽；这会制造双重门框、墙缝、家具和人体结构。

### 人像裁切

- 头顶保留呼吸空间，但不要让天花板占据过多画面。
- 至少保留肩线和一个能解释姿势的手 / 手臂；自拍时尽量保留手机与持机手。
- 不能为了“脸更大”而牺牲身体比例。
- 对“头部靠上、手臂靠下”的竖幅自拍，`focus-y` 可从 `0.55–0.65` 试起；最终以视觉检查为准，不把这个数值机械套给所有照片。

### 食物、花卉与物件裁切

- 主体不应被分界线生硬腰斩。
- 保留一个环境线索即可，如桌面、窗景、叶片或地面；删繁不等于失去场景。

## 3. 下半区：视觉语法

下半区不是照片的低清复制，也不是把主体改画成一幅插画，而是对照片关系的编辑性摘要。核心原则是：**抽象关系，不复刻物体**。观者应先看到负形、块面、方向和节奏，之后才从一个微小线索联想到上图。

### 纸张

- 暖象牙色、轻微纤维、哑光、非纯白。
- 推荐基色：`#F3EEDF`；可在 `#EFE7D5` 到 `#F7F2E7` 间变化。
- 纹理必须细小、低对比，不能像重污渍或复古滤镜。

### 留白

- 目标空白占下半区约 `60–75%`，而且应形成一块连续、可感知的安静区域，不是被碎片切散的空洞。
- 构成群组通常占下半区宽度 `32–55%`、高度 `28–58%`；不要因输入是近景人物就同步放大下半脸部。
- 构成不应同时顶住左右和上下多条边；至少保留一个明显的安静方向。
- 文案与构成群组之间留出清晰呼吸区，不把字塞进轮廓内部。

### 关系优先

- 默认锚点按以下顺序提炼：重心位置、主方向轴、面积比例、层叠 / 遮挡、负形、色彩节奏。完整物件轮廓、完整人物、五官与包装文字不作为默认锚点。
- 使用三级尺度：一个大的负形或未闭合轮廓框；`3–6` 个中尺度矩形、弧形或网点块；`1–3` 个微小点、短线或印记。
- 必须留有一个“空框 / 缺口 / 未完成形”，避免把所有线索闭合成一件完整物体。
- 具象线索是可选的，只允许一个微型符号，通常占下半区宽度 `8–12%`；它是记忆碎片，不是主角。
- 使用大块色面、少量断裂细线、干刷、套色错位与丝网印刷颗粒；避免写实明暗、体积塑形和连续渐变。
- 若下半脱离上图后仍能被直接当作完整的相机、碗、花、购物袋或人物插画，应判定为过于具象并重做。

### 色彩

每张图只用 `4–6` 色。基础色库：

- 暖象牙 `#F3EEDF`
- 炭黑 `#292925`
- 驼棕 `#B68C61`
- 砖红 `#B7392F`
- 芥末黄 `#D69222`
- 灰蓝 `#57758A`
- 鼠尾草绿 `#71806B`

从原图选择一个最有身份感的颜色作为强调色，例如红色手机、豹纹领带、橙色碗或荷叶绿。只借用颜色，不必复制对应物体；其余颜色降低饱和度，让强调色只出现一到两处。

## 4. 按题材抽象关系

### 人像 / 自拍

- 提炼发量块面、姿态轴、肩线 / 手臂方向和 `1–2` 个标志性配件；不默认保留完整人物轮廓。
- 无论上图人脸多近，下半都主动降尺度为小型胸像、半身符号或被纸面吞没的断裂剪影，周围留足空白。
- 皮肤全部或大面积留成纸色，只用少量断裂线提示脸朝向和手势。
- 禁止完整眼睛、虹膜、睫毛、眼妆、鼻部塑形、唇部高光、写实肤色明暗、毛孔或照片级五官相似度。
- 衣服以纸色和大块面为主；只保留最有识别度的一段图案或配色。
- 第一眼若读成一张“大脸肖像”或完整时装插画，而不是负形与姿态关系，必须重做。

### 食物

- 用椭圆边界、堆叠色块、流动线与疏密节奏暗示“容器—内容物—餐具方向”的关系，不闭合画出完整碗盘或餐具。
- 面条、谷物、汤面与配菜只保留少量节奏线、点阵或套色色块，不逐根 / 逐粒描绘。
- 环境最多保留一个未闭合窗框、桌沿或植物负形。

### 花卉 / 植物

- 提取叶片的放射方向、绿白面积关系和深色负形；花只保留一个纸白缺口或不完整花瓣弧线。
- 不闭合画出完整花朵或叶片图鉴；叶脉最多化为几条方向线。
- 深色空隙可以成为构图锚点，但不应吞掉纸面留白。

### 日常物件 / 购物袋 / 随手拍

- 提取下垂方向、矩形叠压、重量、倾斜轴和色彩节奏，不复刻完整袋形、相机、票据或包装。
- 可把一个最关键物件缩成 `8–12%` 宽的微型印刷符号，置于大空框或模块群旁；例如相机只保留一个小小的屏幕块 / 镜头点，而不是画一台大相机。
- 包装文字改为无语义网点或直接省略；不要生成伪品牌字样。
- 人体局部只保留方向关系，通常不画手指和关节；不能增加肢体或改变原有关系。

### 室内 / 场景

- 以一个大负形框和 `3–6` 个正交模块概括桌面、窗、墙和遮挡；透视线最多保留几条。
- 用面积比例和明暗分区暗示空间，不把照片中每件杂物转成小图标。

## 5. 文案系统

- 默认必须有，默认英文；只有用户明确要求无字才省略。若用户指定中文则用短句中文。
- 两行最佳，共 `5–10` 个英文单词；含蓄、安静，与场景有关，不直接描述画面。
- 使用小号经典衬线或打字机感字体，常规字重，不用粗体和全大写。
- 默认字高约 `17–25 px`，行距约 `1.3–1.45`。
- 文案可置于下方中央、左下或构成群组反侧；不要每张都固定在同一位置。
- 图像模型只生成无字底图；使用真实字体在合成后排字，避免伪文字。可运行 `scripts/add_caption.py` 自动选择下半区留白位置。

## 6. 明确排除

- 动漫、Q 版、儿童绘本、厚重水彩、油画、赛博霓虹、3D 渲染。
- 完整物体插画、过度写实的下半人像、大脸肖像、密集钢笔描线、完整照片滤镜化。
- 纯白数字画布、强烈做旧、咖啡渍、撕满全页的 scrapbook。
- 大段文字、大 Logo、边框、贴纸、胶带堆叠、社交媒体 UI。
- 对上半图的任何生成式“优化”。

## 7. 通过标准

缩小到手机屏幕尺寸时，应同时满足：

1. 一眼看出上半是原始照片，而非 AI 复刻；
2. 下半首先读作抽象编辑构成，而不是完整物件 / 人物插画；
3. 通过重心、方向、色彩与空间节奏能感到它对应上半，但无需逐物辨认；
4. 第一感受是“安静、克制、有呼吸”，不是“元素很多、做旧很重”；
5. 上下两种媒介形成反差，但通过负形、强调色和视觉重量彼此呼应。
